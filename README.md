## 🧭 About Me

I'm an MBA in Computer Management professional working at the intersection of **financial markets, data analytics, business analysis, and technology**.

My experience in financial-market research has strengthened my ability to investigate information, verify data against reliable sources, understand market developments, and communicate findings clearly. I enjoy working with datasets, testing whether data can be trusted, building dashboards, and turning raw information into structured, useful insights and clear requirements.

- 📊 **Analytics:** Stock performance, sector trends, risk and returns, funnel and cohort analysis.
- 🧾 **Business analysis:** BRDs, user stories with acceptance criteria, process flows, UAT and A/B test plans.
- 🧪 **Data quality:** API testing and validation of financial data.
- 📈 **Financial research:** Equity markets, IPOs, company filings, and derivatives.
- 🛠️ **Tools:** Python, SQL, Excel, Power BI, Postman, and data visualization.
- 🎓 **Education:** MBA in Computer Management & IT.
- 📜 **Certifications:** NISM Series XV – Research Analyst and NISM Series VIII – Equity Derivatives.
- 🌱 **Currently building:** an e-commerce analytics project (Project 04).

### 📊 Nifty 50 Sector Performance & Risk Analysis

**Python · MySQL · Power BI**

An end-to-end pipeline on five years of NSE data (50 stocks, 16 sectors) that ranks sectors by risk-adjusted return and shows how an investor can diversify.

- Star-schema MySQL database and 8 SQL queries (window functions, CTEs)
- CAGR, volatility, Sharpe ratio, drawdown and beta for every stock
- Found and fixed a demerger distortion and a data-feed error
- 3-page Power BI dashboard

[Explore project →](https://github.com/harsh-1817/nifty50-sector-analysis)

### 🧪 Mutual Fund NAV API: Test & Data-Validation Framework

**Postman · Python · pytest · GitHub Actions**

Tests the public MFapi.in API and checks whether its NAV data can be trusted for valuation and returns.

- 56 Postman assertions and 14 data-quality checks
- Found an API that reports unknown funds as SUCCESS, a single bad NAV record and a 100x break in a fund's history
- Separates real market events from data errors automatically
- HTML, Excel and CSV reports; CI-ready

[View repository →](https://github.com/harsh-1817/mf-nav-api-validation)

### 🧭 Investor Onboarding Drop-off: Business Analysis Case Study

**SQL · Python · Excel · Power BI · BRD**

Why do 7 in 10 people who start opening a trading account never get one? A funnel analysis (synthetic data) with the full business-analysis toolkit.

- 20,000-user funnel, 13 SQL queries, 5-page Power BI dashboard
- BRD, 19 user stories, process flows, UAT and A/B test plans
- Excel impact model: about +11% funded accounts in the base case
- Traceability from finding to requirement to test to KPI

[View repository →](https://github.com/harsh-1817/onboarding-dropoff-analysis)
